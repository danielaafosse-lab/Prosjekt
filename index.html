🏛️ Skattesystem

Skattetype:

Progressive skattetrinn:

Trinn 1: 0 - KKr = 0% (skattefritt)
Trinn 2: 501 - KKr = %
Trinn 3: 1501+ KKr = %
Eks: Ved 3000 KKr lønn betales: 0 + (1000×25%) + (1500×35%) = 775 KKr i skatt
